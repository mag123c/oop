## Chapter2. 객체 지향 프로그래밍

### 구현 과제
`영화 예매 시스템`

### 용어 설명
1. 영화: 영화의 `정보`
- 제목, 상영시간, 가격 정보 등
2. 상영: 관객들이 영화를 관람하는 `사건`
- 상영 일자, 시간, 순번 등
3. 할인 조건
- 가격의 할인 여부를 결정
    3.1. 순서 조건
    - 상영 순번을 이용한 할인 여부 결정 규칙
        - ex: 매일 `10번째`로 상영되는 영화에 할인 적용
    3.2. 기간 조건
    - 상영 시작 시간을 이용한 할인 여부 결정 규칙
        - ex: 월요일 / 오전 10시 ~ 오후 1시 (월요일 오전 10시 ~ 오후 1시 사이 상영되는 모든 영화에 적용)
4. 할인 정책
- 할인 요금을 결정
    4.1. 금액 할인 정책 (절대값)        
    4.2. 비율 할인 정책 (%)

### 요구사항
1. 하나의 영화는 하루 중 다양한 시간대에 걸쳐 한 번 이상 상영될 수 있다.
2. 할인: 할인 조건과 할인 정책을 조합해서 할인을 적용할 수 있다.
    1. 영화 별로 `하나의 할인 정책만 할당`할 수 있다.
    2. `할인 정책을 지정하지 않는 것도 가능`하다.
    3. 할인 조건은 다수의 할인 조건을 지정할 수 있다.
    4. 순서 조건과 기간 조건을 섞는 것도 가능하다.
    5. 할인 정책을 적용하지 않은 경우 영화의 기본 가격이 판매 요금이 된다.
    6. 사용자의 예매 정보와 비교하여 할인 조건을 마족할 경우 할인 정책을 이용해 요금을 할인한다.
